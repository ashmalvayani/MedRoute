This branch serves the MedRoute project website via GitHub Pages.

The source code for the project lives on the [`MedRoute` branch](https://github.com/ashmalvayani/MedRoute/tree/MedRoute).

## Layout

```
.
├── index.html          # Landing page
└── static/
    ├── css/            # Bulma + Font Awesome + custom styles
    └── images/         # Figures (teaser, architecture, results, qualitative)
```

## Enabling GitHub Pages

To serve the site after first push:

1. Open the repo's **Settings → Pages**
2. Set **Source** to *Deploy from a branch*
3. Pick branch **`gh-pages`** and folder **`/ (root)`**
4. Save — the site appears at `https://<username>.github.io/MedRoute/` within ~1 minute
