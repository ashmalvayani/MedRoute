# MedMCQA

Multi-choice medical QA. The loader accepts either layout:

- **Single-file JSON (preferred):** `medmcqa.json` at this folder's root
- **Split-based CSV (alternative):** `data/<split>/*.csv` with columns `question, opa, opb, opc, opd, cop`
